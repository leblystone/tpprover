# Google Play Purchase Option ID

## Purchase Option ID Requirements

- Must start with a number or lowercase letter
- Can contain: numbers (0-9), lowercase letters (a-z), and hyphens (-)
- Maximum 63 characters
- **Cannot be changed after creation** - choose carefully!

---

---

## Important Notes

1. **Purchase Option ID** is for one-time products (like lifetime)
2. **Base Plan ID** is for subscriptions (monthly/annual)
3. **Cannot be changed** after creation
4. **Keep it simple** - you'll reference it in code later if needed
5. **Use lowercase and hyphens** - no underscores, spaces, or uppercase

---

## Purchase Type

For "Purchase type", select:
- **Buy** ✅ (This is correct for a one-time purchase)

This means users buy it once and own it forever (no subscription renewal).
