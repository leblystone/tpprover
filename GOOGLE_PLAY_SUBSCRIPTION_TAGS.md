# Google Play Subscription Tags

## What Are Tags?

Tags are optional labels you can add to subscriptions and offers in Google Play Console. They help you:
- Organize and filter subscriptions
- Track different subscription types
- Group related subscriptions
- Manage promotions and offers

**Tags are optional** - you can leave them blank if you don't need them.

## Best Practices

1. **Keep it simple** - Use short, clear tags
2. **Be consistent** - Use the same naming pattern across all subscriptions
3. **Use lowercase** - Tags are case-sensitive, lowercase is standard
4. **Use hyphens** - Separate words with hyphens (e.g., `recurring-monthly`)
5. **Don't overthink it** - Tags are optional, simple is better

## When to Use Multiple Tags

You might want multiple tags if you plan to:
- Filter by subscription type (`monthly`, `annual`, `lifetime`)
- Filter by tier (`basic`, `premium`, `pro`)
- Track promotions (`promo`, `founder`, `beta`)
- Organize by region (if you have region-specific pricing)

For now, **one simple tag per subscription is fine.**

---

## Important Notes

- Tags are **optional** - you can skip them entirely
- Tags are **case-sensitive** - `Monthly` ≠ `monthly`
- Tags can be **changed later** (unlike Base Plan IDs)
- Tags are for **your organization** - users don't see them
