# 📱 Play Store Release Notes - v1.0.21

## What's New in This Release

### 🛡️ Enhanced Security & Admin Tools
- Improved security management for admin users
- Better handling of suspicious account detection
- Enhanced account deletion system with improved tracking

### 💬 Improved Support System
- New streamlined support options with dedicated forms
- Better bug reporting with Ghost Worker integration
- Feature request system improvements
- Removed duplicate support buttons for cleaner UI

### 👤 Better User Account Management
- Enhanced subscription status tracking
- Improved display of user information in admin tools
- Better handling of lifetime, annual, and monthly subscriptions
- Fixed trial status badge displays

### 🔧 Bug Fixes & Stability
- Fixed protocol activation when linking vials
- Resolved nested subscription object parsing issues
- Fixed JSX rendering errors in support modal
- Improved email template system with full-width layouts

### 📧 Communication Improvements
- Redesigned email templates for better readability
- Backend-only email preview system
- Better email trigger management

### 🎯 Version Management
- New automated version validation system
- Better tracking of app versions across platforms
- Improved update notification system
