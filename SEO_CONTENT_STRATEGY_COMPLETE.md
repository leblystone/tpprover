## 🔍 Where to Add Content in Squarespace

### FAQ Page:
1. Go to **Pages → + Add Page → Blog & Events → Regular Page**
2. Title: "Frequently Asked Questions" or "FAQ"
3. Use **Accordion blocks** for collapsible Q&As
4. Add to **main navigation menu**
5. Add FAQ schema markup to **Settings → Advanced → Code Injection → Footer**

### Blog Posts:
1. Go to **Pages → Blog → + Add Post**
2. Title: Use the **SEO Title** from each blog post
3. Body: Copy-paste the markdown content (Squarespace will format it)
4. **SEO Settings** (click post → Settings → SEO):
   - SEO Title: (already in blog post file)
   - SEO Description: (already in blog post file)
5. Add **Featured Image** (create Canva graphic or product photo)
6. Set **Publish Date** according to schedule
7. Add **Related Articles** links at bottom
