# Store Listing Assets Guide

## Required Assets for App Store Submission

### Google Play Store
- **Feature Graphic**: 1024x500px (banner at top of listing)
- **App Icon**: 512x512px ✅ (already generated)
- **Screenshots**: 
  - Phone: 1080x1920px (portrait) or 1920x1080px (landscape)
  - Tablet: 1200x1920px (portrait) or 1920x1200px (landscape)

### App Store (iOS)
- **App Icon**: 1024x1024px ✅ (already generated)
- **Screenshots**:
  - iPhone 6.7": 1290x2796px
  - iPhone 6.5": 1242x2688px
  - iPad 12.9": 2048x2732px
  - iPad 11": 1668x2388px

## Professional Screenshot Strategy

### Key Screens to Showcase:
1. **Dashboard** - Main interface with your theme
2. **Protocol Creation** - Show the protocol editor
3. **Recon Calculator** - Demonstrate calculation features
4. **Order Management** - Show order tracking
5. **Vendor Management** - Display vendor organization
6. **Stockpile** - Show inventory management
7. **Calendar** - Demonstrate scheduling features

### Screenshot Tips:
- Use your best theme (mauve/sage) for consistency
- Show real data, not empty states
- Add device frames for professional look
- Include captions explaining key features
- Show both light and dark themes if applicable
