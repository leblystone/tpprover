- [ ] Go to http://localhost:5174/app/settings
- [ ] Select "Sage" theme

### 2. Add Sample Data (if needed)
- [ ] Create 2-3 sample protocols
- [ ] Add 2-3 sample orders

## How to Take Each Screenshot

1. Navigate to the URL
2. Wait for page to fully load
3. Scroll to show the most important content
4. Press `Ctrl+Shift+P` in DevTools
5. Type "screenshot"
6. Select "Capture full size screenshot"
7. Save with the suggested filename
8. Repeat for next screen

## Quality Checklist

Before moving to the next screenshot, verify:
- [ ] Full page is captured
- [ ] Text is crisp and readable
- [ ] Sage theme is visible
- [ ] No debug tools or developer indicators visible
- [ ] Real data is shown (not empty states)
- [ ] UI looks professional and polished

## Store-Specific Requirements

### Google Play Store
- Minimum 2 screenshots required
- Maximum 8 screenshots allowed
- Recommended size: 1080x1920px (portrait)
- Format: PNG or JPEG

### App Store (iOS)
- Minimum 1 screenshot required
- Maximum 10 screenshots allowed
- Required size: 1290x2796px (iPhone 6.7")
- Format: PNG or JPEG
