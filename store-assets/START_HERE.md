# 🚀 START HERE - Store Asset Creation Guide

## Welcome! Let's Create Professional Store Assets

This guide will walk you through creating all the assets needed for your app store submission.

## 📋 What You'll Create

1. **Feature Graphic** (1024x500px) - Google Play Store banner
2. **7 Screenshots** - Key app screens in Sage theme
3. **Store Descriptions** - Compelling copy for both stores
4. **App Icons** (already done! ✅)

**Total Time:** ~30-45 minutes

---

## 🎯 Step 1: View Your Feature Graphic (2 minutes)

Your feature graphic with the TPP logo has been created!

1. **Open in browser:**
   ```
   http://localhost:5174/store-assets/feature-graphic.html
   ```

2. **Save as PNG:**
   - Right-click on the graphic
   - "Inspect Element" → Right-click the div → "Capture node screenshot"
   - Or press F12 → Ctrl+Shift+P → "Capture node screenshot"
   - Save as: `store-assets/screenshots/feature-graphic.png`

✅ **Done!** You now have your Google Play Store feature graphic.

---

## 📸 Step 2: Take App Screenshots (20-30 minutes)

### Setup Your App First

1. **Set theme to Sage:**
   - Go to http://localhost:5174/app/settings
   - Select "Sage" theme
   - Save

2. **Make sure you have sample data:**
   - A few protocols
   - Some orders
   - A few vendors
   - Calendar events

### Use the Screenshot Helper

1. **Open the helper tool:**
   ```
   http://localhost:5174/store-assets/take-screenshots.html
   ```

2. **Setup DevTools:**
   - Press F12
   - Click device toggle (📱) or Ctrl+Shift+M
   - Select "iPhone 12 Pro"

3. **Take screenshots:**
   - Click each card in the helper to open that screen
   - Press Ctrl+Shift+P in DevTools
   - Type "screenshot"
   - Select "Capture full size screenshot"
   - Save in `store-assets/screenshots/original/`

### Screenshots You Need:

✅ Dashboard (hero shot)  
✅ Protocols management  
✅ Recon calculator  
✅ Order tracking  
✅ Stockpile inventory  
✅ Vendor management  
✅ Calendar integration

### Common Issues:

**Q: Screenshots look blurry?**  
A: Make sure you're using "Capture full size screenshot" in DevTools, not just a screen grab.

**Q: Theme not showing correctly?**  
A: Go to Settings → Select Sage theme → Refresh page.

**Q: Need different screenshot sizes?**  
A: Change the device in DevTools (e.g., "Pixel 5" for Android, "iPad Pro" for tablets).

**Q: How do I resize screenshots?**  
A: Use online tools like https://www.simpleimageresizer.com or https://bulkresizephotos.com
