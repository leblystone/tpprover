# 📸 Professional Screenshot Instructions

## Quick Start Guide

### Method 1: Browser DevTools (Recommended)
1. **Open your app**: Go to `http://localhost:5173`
2. **Open DevTools**: Press `F12` or right-click → Inspect
3. **Toggle Device Toolbar**: Click the device icon (📱) or press `Ctrl+Shift+M`
4. **Select Device**: Choose "iPhone 12 Pro" for mobile screenshots
5. **Navigate to screens**: Use the URLs below
6. **Take Screenshots**: Press `Ctrl+Shift+P` → type "screenshot" → select "Capture full size screenshot"

### Method 2: Mobile Build (Most Authentic)
1. **Build for mobile**: Run `npm run mobile:build`
2. **Open in Android Studio**: `npx cap open android`
3. **Run on device/emulator**: Take actual device screenshots
4. **Or use iOS Simulator**: `npx cap open ios`

## Screenshot Specifications

### Google Play Store
- **Phone Screenshots**: 1080x1920px (portrait)
- **Tablet Screenshots**: 1200x1920px (portrait)
- **Format**: PNG or JPEG
- **Quality**: High resolution, crisp text

### App Store (iOS)
- **iPhone 6.7"**: 1290x2796px
- **iPhone 6.5"**: 1242x2688px
- **iPad 12.9"**: 2048x2732px
- **iPad 11"**: 1668x2388px

## Pro Tips for Better Screenshots

### 1. Use Real Data
- Don't show empty states
- Use sample protocols, orders, and vendors
- Make it look like a real, active app

### 2. Consistent Theming
- Use your best theme (mauve/sage) for all screenshots
- Maintain consistent colors and styling
- Show the professional, polished look

### 3. Highlight Key Features
- Show the most impressive functionality
- Demonstrate the calculator in action
- Display the protocol management features

### 4. Device Frames (Optional)
- Use online tools like Placeit or Mockup World
- Add device frames for professional look
- Consider both light and dark themes

### 5. Captions and Annotations
- Add text overlays explaining features
- Use arrows or highlights to point out key areas
- Keep captions concise and informative
