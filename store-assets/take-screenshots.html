📸 Screenshot Helper

Professional screenshots for The Pep Planner

🎯 Quick Setup

  1. Press F12 to open Chrome DevTools
  2. Click the device toggle button (📱) or press Ctrl+Shift+M
  3. Select "iPhone 12 Pro" from the device dropdown
  4. Make sure your theme is set to Sage in the app
  5. Click any card below to navigate to that screen
  6. Press Ctrl+Shift+P and type "screenshot"
  7. Select "Capture full size screenshot"
  8. Save with the suggested filename

💡 Pro Tips

  • Use Sage Theme: Make sure your app is set to the Sage theme for consistency
  • Show Real Data: Have sample protocols, orders, and vendors visible (not empty states)
  • Consistent Quality: Take all screenshots at the same device size (iPhone 12 Pro)
  • File Naming: Save as: dashboard-hero.png, protocols-management.png, recon-calculator.png, etc.
  • Full Page: Make sure to capture the full page including any scrollable content
  • Clean UI: Close any debug tools or developer indicators before capturing
