🧪 Update Prompt Tester

Test different update scenarios for The Pep Planner

🟢 Optional Update

User is 1 patch version behind (1.0.3 → 1.0.4). Shows dismissible prompt.

🔵 Recommended Update

User is 1+ minor version behind (1.0.3 → 1.1.0). Shows dismissible prompt with stronger messaging.

🔴 Critical Update

User is below minimum version (1.0.3 < 1.0.4 minimum). BLOCKS app usage - can't dismiss!

📋 How to Test in Your App:

  • Step 1: Run your dev server: npm run dev
  • Step 2: Open DevTools Console (F12)
  • Step 3: Click a test button above
  • Step 4: See the mock data in console
  • Step 5: In your app, trigger the modal manually (see instructions below)
